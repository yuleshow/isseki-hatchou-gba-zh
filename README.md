# 一石八鳥：繁體中文漢化

Game Boy Advance 遊戲《一石八鳥》的繁體中文漢化補丁與建置工具。

**目前為部分漢化預覽版，尚未完成全遊戲翻譯。** 已處理選單、設定及部分局內文字，共 **293 處文字區域**。此數量包含數字變體、共用版面與字形重繪，不等於 293 個互異詞彙，也不是完成百分比。

所有新增中文使用 **Silver** 字型。原有英文提示保持原樣，包括 GO!、WIN、LOSE、DRAW。漢化以文字、字形、顏色及必要的顯示布局調整為主，不修改玩法、牌面、音樂或計分邏輯。

## 使用補丁

| 檔案 | 用途 |
| --- | --- |
| [dist/isseki-hatchou-zh-hant-preview.ips](dist/isseki-hatchou-zh-hant-preview.ips) | IPS 漢化補丁，目前為 136,416 bytes |
| [dist/report.json](dist/report.json) | 翻譯清單、資源位置、字型資訊及驗證配置 |
| [work/isseki-hatchou-zh-hant-preview.gba](work/isseki-hatchou-zh-hant-preview.gba) | 本機建置產生的試玩 ROM，不隨補丁分發 |

1. 自行準備符合下方識別資訊的日版 ROM，並解壓為 `.gba`。
2. 使用支援 ROM 擴容的 IPS 工具，將補丁套用到原版 `.gba`，不要套用到 ZIP 或先前的漢化版。
3. 套用後的 ROM 為 **8 MiB**，可用 mGBA 開啟。
4. 更新補丁後請重新載入 ROM，**不要載入舊版即時存檔**；存檔相容性尚未完整驗證。

本機工作目錄的 ROM 連結只在建置後有效。專案分發補丁，不提供原版 ROM；請勿提交或分發生成的 ROM。

### 麻將

- 操作文字統一使用 12 像素 Silver，原紅色改為黃色，原藍色改為亮綠色。
- HUD 使用「寶／餘」，跳過提示放大並保留 B 鍵圖示。
- 修正「ノーテン親流れ」為「未聽牌輪莊」，不再誤譯成「立直流局」。
- 結算字庫的 106 個完整字形、十個小數字，以及「滿貫／跳滿／倍滿／三倍滿／役滿」統一字型；其中仍有假名詞組未完成翻譯。
- 結算行距與底列位置已調整，保留原計分邏輯。字庫與離線排版檢查不代表自然胡牌流程已驗證。

### 大富豪與撲克

大富豪包含「不出、跳過、革命、王政復古、8切牌、J反轉、逆轉方向、交換中」等宣告，以及交牌、收牌、選擇一張／兩張牌的提示。換牌文字保留原十幀、三字分別跳動的動畫布局。三頁設定的行格、分隔線及選項位置保留原樣。

撲克牌型包含「高牌、一對、兩對、三條、四條、五條、順子、同花、葫蘆、同花順、皇家同花順」；操作包含「底注、加注、下注、跟注、全下、過牌、棄牌」。宣告與選單各自的圖塊均已處理。

## 本機建置

目前工具以 **macOS** 為目標，需 Node.js、ImageMagick、FFmpeg、Homebrew mGBA、Xcode 命令列工具，以及 [assets/Silver.ttf](assets/Silver.ttf)。既有驗證環境使用 Node.js 26、mGBA 0.10.5、ImageMagick 7。

自行準備原版 ZIP，放入 `assets/`。檔名須為 `Isseki Hatchou - Kore 1ppon de 8shurui! (Japan).zip`，與 [tools/inspect-rom.mjs](tools/inspect-rom.mjs) 的來源設定一致。從專案根目錄執行：

```sh
node tools/build.mjs
```

建置會校驗原版、編譯無視窗 mGBA 擷取工具、擷取測試資料、產生漢化 ROM／IPS／報告，並執行已配置的字形、顯存、地圖、調色板、OAM 和補丁回讀檢查。畫面與原始快照輸出至本機工作目錄。

`MGBA_PREFIX` 可指定 mGBA 安裝目錄，`MACOS_SDK` 可指定 SDK。預設優先使用已安裝的 macOS 26.5 SDK，以避開本機 macOS 27 SDK 與連結器不相容問題。翻譯固定使用 Silver，不讀取 `ZH_FONT` 覆寫。

已有原版擷取資料時，可只重建翻譯：

```sh
node tools/localize.mjs
```

### 個別檢查

以下命令依賴已生成的 ROM、報告及相應擷取資料，不能取代完整建置：

```sh
node tools/check-retry.mjs
node tools/check-results-layout.mjs
node tools/check-action-colors.mjs --bubbles
node tools/check-background-layouts.mjs
node tools/check-poker.mjs --capture
node tools/check-daifugo.mjs --capture
node tools/check-flower.mjs
```

花札工具的 `--capture` 額外模式依賴開發時保留的舊版開局快照，不是通用的首次建置入口；常規構建使用其離線字圖檢查，另檢查開局載入資源。

資源掃描與壓縮自測：

```sh
node tools/inspect-rom.mjs --self-test
node tools/inspect-rom.mjs scan
```

## 技術備註

文字主要儲存為 4bpp 圖塊，背景地圖包含 16-bit 寬高與圖塊索引，已處理 30×20 和 32×32 版面。精靈文字可能共用字塊、以不同調色板重複顯示，或分成多組動畫；修改會保留未處理像素，並檢查共用位置的寫入一致性。

Silver 的中文字寬換算為 12 像素字格時使用 19 點渲染，停用抗鋸齒並檢查筆畫是否超出可見範圍。少數布局需要精靈重排、獨立文字資源或座標調整，具體修改記錄於報告。

GBA BIOS 的顯存 LZ77 解壓不適用距離為 1 的回引用，壓縮器會排除此情形。超出原壓縮空間的資源會重定位並更新指標；除了軟體回讀，仍需模擬器顯存檢查，不能只憑字圖預覽判定成功。

麻將顯示樣本的 `mahjong-preview:animation` 只暫時修改模擬器記憶體中的動畫指標，不寫回分發 ROM，也不能當作自然遊戲證據。擷取工具同時輸出 IWRAM、VRAM、OAM、調色板等資料供追蹤。
